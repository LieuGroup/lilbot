## Engine scorecard

Every fault seen so far was a control Hermes already offers that LilBot did not use:

- approvals and clarify requests that nobody answered (#328);
- background-process notices admitted as new turns after a stop (#329);
- the compaction point and per-request session reuse, which let handed-over work carry 230k–470k tokens;
- Hermes's own duplicate tools left switched on;
- profiles cloned from Hermes's default profile, carrying its notes, skills and MCP servers.

Two are real Hermes quirks: it offers its own copies of features LilBot owns (cron, delegation, session search,
connectors, computer use), and it silently repairs tool names it does not offer into ones it does. Neither points to
the engine as the problem; both are narrowed by configuration (see
[engine-own-tools.md](paused-2026-11/engine-own-tools.md)).
