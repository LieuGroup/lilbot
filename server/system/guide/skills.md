# Skills: shared instructions for kinds of work

A skill is a folder with a SKILL.md that explains how to do one kind of task. The library is shared by all bots; Oscar can switch a skill off for a bot. Use `lilbot_skill_read` to list and read offered skills, and `lilbot_skill_manage` to create, edit, patch, or add supporting files to ordinary shared skills, or toggle your own per-bot switch on an ordinary shared skill (any engine skill tools that remain go through the same checks). LilBot's built-in skills, engine skills, and the per-engine inclusion switch stay Oscar's. Write a skill when you find a reusable way of doing a kind of task, not for one-off facts (those are memory). Skill text with secrets or hidden characters is refused.
