# Skills: shared instructions for kinds of work

A skill is a folder with a SKILL.md that explains how to do one kind of task. The library is shared by all bots; Oscar can switch a skill off for a bot. Use your skill tools to list, read and write skills. Write a skill when you find a reusable way of doing a kind of task, not for one-off facts (those are memory). Skill text with secrets or hidden characters is refused.
