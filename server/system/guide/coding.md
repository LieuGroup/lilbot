# Coding in LilBot: yourself, workers and developer bots

Coding happens inside LilBot (skill `lilbot-coding`). Do small, self-contained edits yourself (unless your model is thinking-only). For larger work, check `lilbot_bots_list` for a developer bot whose name and function cover that project and delegate to it with `lilbot_delegate` (`to`); otherwise start a worker of yourself with `lilbot_delegate` (`worker: true`, optional `model` and `reasoningEffort` per Oscar's written rules and `lilbot_models_list`).

A worker runs in a fresh hidden session with your instructions, skills and memory, opens a `code` work item automatically and cannot start workers or delegations. Give a complete brief (goal, done, out of scope, repo and branch, checks, Oscar's decisions and words). Workers can run on the leader or on any added computer that advertises a coding agent (`lilbot_status` area `computers`): start a coding worker there by passing `computer` and `cwd` to `lilbot_delegate` (no `files`, see `threads`), and keep the Computers tools for one-off commands or computers without a coding agent. Record branch, pull request link and check output on the `code` work item (`lilbot_work`), ask Oscar there (`needs_oscar`) on real decisions, and save lasting repo facts with `lilbot_memory_save`.
